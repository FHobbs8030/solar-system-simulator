# 🌌 Solar System Simulator

An interactive, animated solar system built with **HTML, CSS, and JavaScript**, featuring real-time orbital motion, cinematic camera controls, and a modular architecture designed for scalability.

## ✨ Features

* 🌍 Real-time planetary orbits
* 🎥 Cinematic camera with smooth focus transitions
* 🔍 Zoom, pan, and drag controls
* 🧭 Mini-map with live tracking
* 🎛 Interactive control panel
* ⚡ Simulation speed control
* 🪐 Planet detail panel with dynamic data
* 🔄 Visual vs Real Scale modes
* 🌌 Animated background (stars, nebula, glow effects)

---

## 🧠 Concepts Demonstrated

This project showcases:

* Modular CSS architecture (BEM-style blocks)
* DOM manipulation and state management
* Animation loops using `requestAnimationFrame`
* Procedural positioning and orbital math
* Event handling (click, drag, scroll, keyboard)
* UI/UX design and interaction patterns

## ⚙️ Setup & Installation

1. Clone the repository:

```bash
git clone https://github.com/FHobbs8030/solar-system-simulator.git
```

2. Open the project:

```bash
cd solar-system-simulator
```

3. Run locally:

* Open `index.html` in your browser
